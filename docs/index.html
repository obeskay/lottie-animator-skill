Lottie Animator
SVG to motion, verified

A broken Lottie still parses. This skill converts SVG to Lottie, lints the defects that render blank, and renders the result in a real player — so the animation is looked at before it ships.

View on GitHub Quick Install

What it actually does

Real SVG conversion

Full path grammar including elliptical arcs, plus groups, nested transforms, strokes and gradients. No hand-written vertex maths.

Linting that finds blanks

Missing shape properties, easing handles on the wrong object, dead layers, unpainted geometry, loops that never close.

Headless rendering

Loads the file in real lottie-web and writes a labelled filmstrip, flagging empty, clipped and off-canvas frames.

Standard Lottie out

Plain Lottie JSON for web, iOS, Android and React Native. Python tooling has no dependencies at all.
