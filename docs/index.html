A Claude Code skill for Lottie. Twenty-two recipes that re-skin in nine palettes, a converter that does the bezier arithmetic, a linter for the defects that render blank, and a renderer that makes the agent look at every frame it claims is done.

Palette

Build, lint, render, look.

Recipes, not blank pages

Each example is a short Python generator. Copy the nearest one, change the beats, keep the timing. --palette night re-skins it.

Taste as tokens

motion.py holds the house style: strong ease-out, zero overshoot, holds at rest, colour by role. Every keyframe it writes carries its easing handles.

A linter for silent failures

A broken Lottie still parses. The linter catches the defects that render blank: missing properties, misplaced handles, layers that never play.

Then it looks

A headless lottie-web renders a filmstrip and an onion skin. The agent reads them and judges spacing, arcs and rest before it says done.
